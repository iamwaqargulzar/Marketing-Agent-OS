# Changelog

## 1.1.0 — 2026-08-11

- Renamed the product and package to Marketing Agent OS.
- Added Linux/macOS and Windows installation entry points plus additional agent targets.
- Added seven missing upstream-compatible GEO/SEO adapter skills.
- Replaced 145 generic trigger descriptions with specific routing descriptions.
- Removed the duplicated plugin payload by making the repository root the plugin.
- Hardened installer replacement, URL fetching, JSON-LD generation, manifests, and validation.
- Added cross-platform tests and verified discovery of all 235 skills.
- Added complete pinned snapshots of all four upstream repositories.
- Added atomic upstream checking/updating, lock hashes, reconciliation, and local maintenance documentation.
- Added a citation-friendly public repository page, `llms.txt`, citation metadata, support and security policies, issue forms, pull-request checks, and dependency maintenance.
- Published the canonical public repository as `iamwaqargulzar/Marketing-Agent-OS` and standardized the root Apache-2.0 license for GitHub detection.

## 1.0.0 — 2026-08-10

- Initial unified release.
- Normalized four upstream capability sets into one Agent Skills package.
- Added cross-agent installer, conflict-resolution policy, evidence/permission governance, SEO/GEO portable scripts, tool registry, schema templates, specialist agents, legacy aliases and integrity manifest.
