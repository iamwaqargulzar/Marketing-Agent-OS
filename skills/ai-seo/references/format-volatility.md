# AI Citation Format Volatility

Use this reference when choosing page formats for AI-search visibility or interpreting citation changes.

## Principles

- Treat citation performance by page type as platform-specific and time-bound. A change observed on one answer engine is not evidence that every engine changed.
- Do not justify scaled listicles, comparison pages, or other templates solely with an AI-citation claim. Choose formats for the user's intent and business value first.
- Prefer durable primary-source assets when the organization can uniquely support them: product and service facts, documentation, pricing, original research, methods, and transparent evidence.
- Keep useful comparison and best-of content when it serves real buyers; evaluate it by human usefulness, conventional search value, conversion evidence, and each target engine separately.
- Label third-party visibility studies as **proxy** or **estimated**, including their platform, sample, collection date, and method. Verify material recommendations against current first-party documentation and the user's own monitoring.

## Measurement

AI answers are non-deterministic. Repeat important prompts in independent sessions, report the number of runs, and track mention or citation rate rather than a one-run yes/no result. Compare like-for-like query sets and platform versions over time.

Before prescribing a content-format fix, separate three failure classes:

1. **Technical:** the source cannot be crawled, rendered, parsed, or accessed.
2. **Comprehension:** the system describes the entity, offering, or answer inaccurately.
3. **Selection/trust:** the source is understood but not chosen or cited.

Recommend format changes only after identifying which class the available evidence supports.
