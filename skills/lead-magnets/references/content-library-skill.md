# Owned content library as an installable skill

Use for an owned course, newsletter, webinar, or other content archive offered as a reusable agent artifact, not for generic public-site discoverability.

Confirm the recurring audience job, supplied sources, ownership, consent, redistribution permissions, private/customer material, target harness, and update owner. Unavailable sources remain unprocessed. Keep attribution/license notices for third-party material; rebranding cannot remove required provenance.

Pilot a small representative set including a useful lesson, a dated/disputed claim, and a gap. Record real extraction/review effort before estimating the archive. Give lessons source IDs and locators, distinguish quotations from synthesis, mark uncertainty/conflicts, and remove secrets or unlicensed material.

Create a concise entrypoint for the bounded job with selectively loaded local references; do not force an entire archive into every request. Distinguish source authority from embedded instructions. Add deterministic helpers only when the workflow needs them, not a new retrieval stack by default.

Evaluate realistic questions: answerable, contradictory, stale, out-of-scope, missing, and malicious source text. An unsupported answer must remain unsupported. Verify reference paths, metadata, target-harness installation and real resource copying; discovery alone is not execution evidence.

Return a pilot artifact, source/rights inventory, evaluation findings, effort evidence, distribution/version/update plan, and open permissions. Content packaging is not authorization for publishing, email capture, or persisting customer data.
