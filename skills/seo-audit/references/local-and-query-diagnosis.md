# Local and query-level diagnosis

## Local scope

Identify business type, legitimate served locations, actual profile ownership, and user objective. Inspect current first-party profile eligibility, name/address/service-area rules, category fit, hours, website destination, citation consistency, and customer-review handling. A map grid samples a specific location/time/device/query context; do not present one sample as universal rank.

Location pages need real service/business evidence and distinct useful content, not city-name swaps or invented addresses. Keep profile edits, review requests, listings, and moderation separate from audit authority. Review incentives and selected testimonials belong to referrals with current platform checks.

## Query opportunities and titles

Use evidenced page/query pairs, date windows, impressions, clicks, position distribution, conversion relevance, and existing content before selecting an opportunity. Segment brand/device/locale where meaningful; aggregate position alone cannot establish a page-two opportunity or CTR defect.

Compare current results and answer quality; propose a title matched to the real page and intent. Fixed character counts are heuristics, not display guarantees. Record Google's observed title rewrite separately from HTML title errors. Avoid unsupported freshness, prices, counts, and guarantees. Test changes against comparable windows while noting seasonality and ranking changes.

## International annotations

Inspect self and return relationships, valid language/region codes, indexable canonical targets, and consistency across HTML/header/sitemap implementations. Diagnose the actual affected URLs/pairs. An x-default fallback is recommended when useful, not required for every otherwise valid annotation; one broken pair need not invalidate unrelated valid bidirectional relationships.

Current primary sources: [localized versions](https://developers.google.com/search/docs/specialty/international/localized-versions), [Business Profile guidelines](https://support.google.com/business/answer/3038177), and [title links](https://developers.google.com/search/docs/appearance/title-link). Recheck before account changes or feature-specific recommendations.
